# D&D_k-Means
K-means é uma dos algoritmos mais conhecidos no mundo da computação, e para realizar o estudo apliquei no universo de RPG para analisar os tipos de classes existentes, calssificando para entender melhor o perfil de cada uma. Assim, falicitando na escolha entre jogar com magia, força ou algo mais equilibrado.

## Requisitos
1. Python 3.6 ou maior
2. Pandas: Para explorar e fazer a leitura dos dados
3. Matplotlib: Para a visulização dos dados
4. Scikit-Learn: Para a criação do modelo
